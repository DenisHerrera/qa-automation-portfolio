# QA Automation Portfolio

Personal learning portfolio built while following a 12-week QA Automation study plan.
The goal is to practice and demonstrate skills across the full QA automation stack:
CI/CD, API testing, contract testing, TypeScript, AI-assisted QA, quality metrics,
and performance testing.

See [`PROGRESS.md`](./PROGRESS.md) for the detailed weekly log, review scores, and notes.

## Roadmap

| Week | Topic |
| --- | --- |
| 1 | Framework base (Playwright + Java + Cucumber) |
| 2 | CI/CD: GitHub Actions, Docker, Allure |
| 3 | API testing: HTTP, REST Assured |
| 4 | Postman, Newman, API + UI |
| 5 | SQL, MySQL, Testcontainers |
| 6 | Contract testing with Pact |
| 7 | TypeScript + Playwright Test |
| 8 | Advanced Playwright |
| 9 | Claude Code skills, Playwright MCP and Agents |
| 10 | AI in CI/CD, LLM evaluation |
| 11 | Quality metrics dashboard (Python) |
| 12 | Performance with k6, final polish |
